# Retrieval Scope

Reproduced: BM25 mechanics, deterministic LSA, RRF, a bounded feature reranker,
and standard retrieval metrics.

Not reproduced: DPR training/inference, neural cross-encoding, original
datasets, original preprocessing, headline values, and significance tests.

Exact command:

```text
paper-repro run --study retrieval --output research/results/v0.1
```
